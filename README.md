# Okikiola Omotosho - Portfolio

Vite + React + TypeScript + Tailwind CSS + Framer Motion.

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - typecheck and build to `dist/`
- `npm run preview` - serve the production build

## Editing content

All content lives in `src/data/`:

- `profile.ts` - name, intro, email, socials, skills, tools, bio
- `projects.ts` - projects (currently dummy data)
- `career.ts` - experience and education

The previous version of the site is tagged `v1-portfolio`.
